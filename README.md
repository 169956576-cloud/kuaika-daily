# kuaika.com · 三角洲每日行情

一个用于《三角洲行动》卡战备和特勤处制造计算的网站。中文界面，适配电脑和手机；默认自动参考用户指定的准星工具站公开页面。

## 打开网站

使用 Node.js 22 或更新版本，在此文件夹运行 `node server.mjs`，然后打开 http://localhost:3211/ 。Windows 也可右键“启动网站.ps1”，选择“使用 PowerShell 运行”。

本机预览地址仅在服务运行时可用。GitHub Pages 云端由 GitHub Actions 每 30 分钟左右获取一次准星公开页面数据并自动发布，无需你的电脑在线。GitHub 定时任务可能因平台调度而稍有延迟。初次部署地址为 `https://169956576-cloud.github.io/kuaika-daily/`，可供其他设备访问。域名 `kuaika.com` 尚未绑定，待 DNS 配置后再添加自定义域名记录。

在已完成 `gh auth login` 的 PowerShell 中运行“发布到GitHub.ps1”，创建公开仓库并推送网站。首次推送后等待 GitHub Actions 完成，再打开上面的 Pages 地址。同步失败时仍会部署页面，并按数据日期显示旧快照状态。

独立云端定时器程序已准备在 `cloud-scheduler/`，新账号配置步骤见 [配置说明](cloud-scheduler/配置说明.md)。它需要完成 Cloudflare 登录、GitHub 授权和部署才会生效；目前保留 GitHub 原有定时器。抓取最多重试 3 次，全部失败时保留旧数据并将运行标记为失败。

## 没有接口密钥也能使用

- 在“每日卡战备”下展开录入表，输入游戏内当天买入价、逐项战备价值和实际进场门槛。总花费、总战备值和达标情况自动计算；已达标的当天配装参与最低成本统计。这里不推定装备位置、负重或耐久等额外规则，进场以游戏结算为准。
- 在“自定义收益”输入当天成品价格、产量、总材料成本、综合费率和设施实际制造时长。结果会加入制造排行，可按设施、小时收益、单次收益和时长筛选。
- 手动价格必须带采集时间，历史日期不会加入当天统计。当天价格超过 30 分钟会提示核价。
- 手动数据只保存在当前浏览器。关闭网页不会清除，但清理浏览器存储或换浏览器会丢失。生产排队、离线停工和成交速度未计入，不把每小时利润乘 24 当成保证日收入。

## 数据口径

准星的卡战备数据自带更新时间；制造页面未披露价格采集时间、设施等级与手续费口径，因此页面把制造数值标为“参考收益”，不声称是你自己的实际净利润，也不按等级筛选。历史快照不会参与当天制造排行；来源失败时保留手动填写结果并标明过期。采集程序只读取准星公开页面，不登录、不访问游戏账号、不绕过访问限制。

## 可选数据接口

1. 到 https://orzice.com/work/ 自行获取有效 Token。本站没有内置密钥，也不会索要游戏账号。
2. 复制 `.env.example` 为 `.env`，填写 `DELTA_API_TOKEN=你的密钥` 和 `DATA_SOURCE=orzice`。
3. 停止原先运行的服务器后重新运行 `node server.mjs`，点击刷新。

后端固定请求 `https://orzice.com/workApi` 下的文档接口，密钥不传给网页：

- `GET /v1/sjz_api/jzv4_zb?lv=...`：配装总成本、战备值、门槛、物品清单与源数据采集时间。排除名称含“兑换”的组，按相同物品清单去重，按实际总花费排序。
- `GET /v1/sjz_api/manufacturePro?t=...&l=...`：技术中心、工作台、制药台、防具台。按实际设施等级请求。`price` 是净利润，`price_hour` 为小时净利润，`period` 为小时数；直接采用源数据计算结果，不重复扣除费用。

接口文档：https://work-api.apifox.cn/457269341e0.md 、https://work-api.apifox.cn/422150879e0.md 。本机获取时间和源数据采集时间分开标注。制造接口不提供采集时间，因此页面明确提示“行情采集时间未知”，不保证是当前成交价。

同一战备档位与设施等级的结果在服务器内缓存 10 分钟，同一个缓存键的并发请求合并。每次新组合最多请求 5 个接口；切换筛选、重启服务器或到期刷新可能消耗服务商额度。不同组合不共用缓存。接口部分失败会显示具体模块；全部失败会清除推荐并显示错误，不回填示例。无密钥时不调用上游。

## 示例与限制

“体验示例”仅显示接口文档中的历史样例，不是当天真实行情，不可据此购买。由于文档只提供技术中心的制造样例，示例下其他设施没有项目；更高战备档位没有配装样例。点击“退出示例”或“刷新情报”恢复实际模式。

已验证准星公开页面同步成功并返回当天数据。外部页面的数据口径和可用性可能变化；来源未提供制造物价采集时间，因此交易前仍需在游戏内核价。可选接口需要用户自行提供有效密钥，本站不内置密钥。
